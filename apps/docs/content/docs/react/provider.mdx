`tanstackQueryPlugin()` does not create its own provider. It calls `useQueryClient()` internally, which means it reads from whatever `QueryClientProvider` is already in your component tree. You are responsible for mounting one.

This is intentional — it means Nexus Framework integrates into your existing TanStack Query setup without adding a second React context layer.

---

## Mount QueryClientProvider

<Tabs items={["TanStack Start", "Next.js"]}>
  <Tab value="TanStack Start">

  In TanStack Start, pass a `Wrap` function to `createTanStackRouter`. This is exactly how SignUIT does it:

  ```tsx title="src/router.tsx"
  import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
  import { createRouter as createTanStackRouter } from '@tanstack/react-router';
  import { routeTree } from './routeTree.gen';

  export const queryClient = new QueryClient({
    defaultOptions: {
      queries: {
        staleTime: 5_000, // [!code highlight]
        retry: 2,
      },
      mutations: {
        retry: 0, // Never retry a failed ledger command — side effects may have occurred // [!code highlight]
      },
    },
  });

  export const getRouter = () =>
    createTanStackRouter({
      routeTree,
      context: { queryClient },
      Wrap: ({ children }) => ( // [!code highlight]
        <QueryClientProvider client={queryClient}> // [!code highlight]
          {children} // [!code highlight]
        </QueryClientProvider> // [!code highlight]
      ),
    });
  ```

  `nexus.*` hooks work anywhere inside this tree — no additional wrapping needed.

  </Tab>
  <Tab value="Next.js">

  Create the `QueryClient` at module level (outside the component) and pass it to `QueryClientProvider` in a `'use client'` component:

  ```tsx title="components/providers.tsx"
  'use client';
  import { QueryClient, QueryClientProvider } from '@tanstack/react-query';

  const queryClient = new QueryClient({
    defaultOptions: {
      queries: { staleTime: 5_000, retry: 2 }, // [!code highlight]
      mutations: { retry: 0 }, // [!code highlight]
    },
  });

  export function Providers({ children }: { children: React.ReactNode }) {
    return (
      <QueryClientProvider client={queryClient}> // [!code highlight]
        {children}
      </QueryClientProvider>
    );
  }
  ```

  ```tsx title="app/layout.tsx"
  import { Providers } from '@/components/providers';

  export default function RootLayout({ children }: { children: React.ReactNode }) {
    return (
      <html><body>
        <Providers>{children}</Providers>
      </body></html>
    );
  }
  ```

## Why staleTime matters

Canton ledger finality typically takes 3–10 seconds. Without `staleTime`, TanStack Query refetches on every component mount — which means multiple rapid fetches before a transaction is even committed. Setting `staleTime: 5_000` means the cache is served immediately on mount and only a background refetch runs once the data is 5 seconds old.

---

## Why mutations.retry: 0

Ledger commands are not idempotent by default. If a `createContract` call succeeds on the Canton side but the response is lost in transit, retrying will submit the command twice. Set `retry: 0` for mutations and handle errors explicitly.

## Sharing the QueryClient with context

If you need to access `queryClient` in server functions or route loaders, pass it through the router context:

```tsx title="src/router.tsx"
export interface RouterAppContext {
  queryClient: QueryClient;
}

export const getRouter = () =>
  createTanStackRouter({
    routeTree,
    context: { queryClient }, // [!code highlight]
    Wrap: ({ children }) => (
      <QueryClientProvider client={queryClient}>{children}</QueryClientProvider>
    ),
  });
```

Then access it in loaders:

```tsx title="src/routes/dashboard/index.tsx"
export const Route = createFileRoute('/dashboard/')({
  loader: async ({ context }) => {
    const { queryClient } = context;
    await queryClient.prefetchQuery(/* ... */);
  },
});
```
