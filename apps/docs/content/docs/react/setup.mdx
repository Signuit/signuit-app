`createNexusClient` is the React client factory from `@nexus-framework/react`. It takes a plugins array and returns a fully configured client — the hooks, the auth, and the typed namespaces all come from the same instance. There is no shared React Context to configure and no separate import path for each feature.

This design is inspired by [better-auth](https://better-auth.com): you create the client once, and everything you need is a property on it.

---

## The two auth patterns

Before creating the client, choose the right auth pattern for your environment:

| Pattern | Plugin | When to use |
|---------|--------|-------------|
| **Session-based** | `authPlugin()` | Production. The browser never sees the Canton token — it lives in an HttpOnly cookie on the server. |
| **Direct sandbox** | `sandboxAuth()` | Development only, when you don't have a server layer. |

SignUIT uses `authPlugin()`. If you're building anything beyond a local demo, use `authPlugin()`.

---

## Production setup with authPlugin

This requires the server to be wired up first. See [Core: Server](/docs/core/server) for `createNexusServer` and `createAuthHandler`. Once the `/api/nexus-auth` and `/api/ledger` routes exist on your server, create the browser client:

```ts title="lib/nexus-client.ts"
import { createNexusClient, authPlugin, tanstackQueryPlugin } from '@nexus-framework/react';
import { nexusTypes } from './nexus-types';

export const nexus = createNexusClient({
  baseUrl: '/api/ledger',
  plugins: [
    authPlugin({ basePath: '/api/nexus-auth' }),
    tanstackQueryPlugin(),
    nexusTypes,
  ],
});
```

Three plugins, three jobs:

| Plugin | What it does |
|--------|-------------|
| `authPlugin` | Reads the session cookie and attaches the Canton JWT to every request. The token never touches the browser bundle. |
| `tanstackQueryPlugin` | Adds `useContracts`, `useCreateContract`, `useExerciseChoice`, and all other hooks to the `nexus` instance. |
| `nexusTypes` | Unlocks `nexus.types.CollateralHolding.useContracts()` and every other typed template namespace. |

## Add the provider

`nexus.NexusProvider` is not a standalone import — it is a property on your `nexus` instance. This ensures the provider is always bound to the client that created it.

<Tabs items={["TanStack Start", "Next.js"]}>
  <Tab value="TanStack Start">
  ```tsx title="src/routes/__root.tsx"
  import { createRootRoute, Outlet } from '@tanstack/react-router';
  import { nexus } from '@/lib/nexus-client';

  export const Route = createRootRoute({
    component: () => (
      <nexus.NexusProvider>
        <Outlet />
      </nexus.NexusProvider>
    ),
  });
  ```
  </Tab>
  <Tab value="Next.js">
  ```tsx title="components/providers.tsx"
  'use client';
  import { nexus } from '@/lib/nexus-client';

  export function Providers({ children }: { children: React.ReactNode }) {
    return <nexus.NexusProvider>{children}</nexus.NexusProvider>;
  }
  ```

  `NexusProvider` uses React hooks so it must be in a `'use client'` component.
  </Tab>
</Tabs>

## Use hooks in components

Import `nexus` from your client module and call hooks directly on it. No `useContext`, no separate import for each hook:

```tsx
import { nexus } from '@/lib/nexus-client';

// Typed — no generic parameter, no templateId string
const { data } = nexus.types.CollateralHolding.useContracts();

// Auth hooks from authPlugin
const { data: session } = nexus.auth.useSession();
```

## Development setup with sandboxAuth

If you need to query Canton directly without a server — for local scripts, sandbox demos, or isolated component testing:

```ts title="lib/nexus-client.ts"
import { createNexusClient, sandboxAuth, tanstackQueryPlugin } from '@nexus-framework/react';
import { nexusTypes } from './nexus-types';

export const nexus = createNexusClient({
  baseUrl: 'http://localhost:7575',
  plugins: [
    sandboxAuth({
      secret: process.env.SANDBOX_SECRET ?? 'secret',
      userId: 'alice',
      partyId: process.env.SANDBOX_PARTY_ID ?? 'Alice::122059a10c...',
    }),
    tanstackQueryPlugin(),
    nexusTypes,
  ],
});
```

<Callout type="warn">
  `sandboxAuth` puts the HMAC secret directly in your browser bundle. Never use it in production. For production, always use `authPlugin` with a server-side `createNexusServer` setup.
</Callout>
