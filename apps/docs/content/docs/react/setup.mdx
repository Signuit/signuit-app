`createNexusClient` is the React client factory from `@nexus-framework/react`. It returns a fully configured instance — hooks, auth, and typed namespaces are all properties on it. There's no shared React Context to wire separately and no per-feature import path.

This design is inspired by [better-auth](https://better-auth.com): create the client once, use everything from it.

---

## The two auth patterns

| Pattern | Plugin | Use when |
|---------|--------|---------|
| **Session-based** | `authPlugin()` | Production. Token lives in an HttpOnly cookie — never in the browser bundle. |
| **Direct sandbox** | `sandboxAuth()` | Local development only, no server layer needed. |

<Callout type="warn">
  `sandboxAuth` embeds the HMAC secret in your browser bundle. Use `authPlugin` for anything beyond a local demo.
</Callout>

## Production setup

The server must be running first — `createNexusServer` and `createAuthHandler` at `/api/nexus-auth` and `/api/ledger`. See [Core: Server](/docs/core/server).

Once the server routes exist, create your client:

```ts title="lib/nexus-client.ts"
import { createNexusClient, authPlugin, tanstackQueryPlugin } from '@nexus-framework/react';
import { nexusTypes } from './nexus-types';

export const nexus = createNexusClient({
  baseUrl: '/api/ledger',
  plugins: [
    authPlugin({ basePath: '/api/nexus-auth' }), // [!code highlight]
    tanstackQueryPlugin(), // [!code highlight]
  ],
  types: nexusTypes, // [!code highlight]
});
```

Three configuration points, three jobs:

| Config | What it does |
|--------|-------------|
| `authPlugin` | Reads the session cookie and attaches the Canton JWT to every request. The token never touches the browser bundle. |
| `tanstackQueryPlugin` | Adds `useContracts`, `useCreateContract`, `useExerciseChoice`, and all other hooks. |
| `types: nexusTypes` | Unlocks `nexus.types.X.*` — typed hooks where templateId and payload shape are inferred from your Daml codegen. |

## Provider

`nexus.NexusProvider` is a property on your instance — not a standalone import. This keeps the provider bound to the exact client that created it.

<Tabs items={["TanStack Start", "Next.js"]}>
  <Tab value="TanStack Start">
  ```tsx title="src/routes/__root.tsx"
  import { createRootRoute, Outlet } from '@tanstack/react-router';
  import { nexus } from '@/lib/nexus-client';

  export const Route = createRootRoute({
    component: () => (
      <nexus.NexusProvider> // [!code highlight]
        <Outlet />
      </nexus.NexusProvider> // [!code highlight]
    ),
  });
  ```
  </Tab>
  <Tab value="Next.js">
  ```tsx title="components/providers.tsx"
  'use client'; // [!code highlight]
  import { nexus } from '@/lib/nexus-client';

  export function Providers({ children }: { children: React.ReactNode }) {
    return <nexus.NexusProvider>{children}</nexus.NexusProvider>;
  }
  ```

  `NexusProvider` uses React hooks — it must live in a `'use client'` component.
  </Tab>
</Tabs>

## Using hooks

Import `nexus` and call hooks directly. No `useContext`, no separate import for each feature:

```tsx
import { nexus } from '@/lib/nexus-client';

const { data } = nexus.types.CollateralHolding.useContracts(); // typed, no generic // [!code highlight]
const { data: session } = nexus.auth.useSession();
```

## Development setup

For local scripts, sandbox demos, or quick prototypes without a server:

```ts title="lib/nexus-client.ts"
import { createNexusClient, sandboxAuth, tanstackQueryPlugin } from '@nexus-framework/react';
import { nexusTypes } from './nexus-types';

export const nexus = createNexusClient({
  baseUrl: 'http://localhost:7575',
  plugins: [
    sandboxAuth({ // [!code highlight]
      secret: process.env.SANDBOX_SECRET ?? 'secret',
      userId: 'alice',
      partyId: process.env.SANDBOX_PARTY_ID ?? 'Alice::122059a10c...',
    }),
    tanstackQueryPlugin(),
  ],
  types: nexusTypes, // [!code highlight]
});
```
