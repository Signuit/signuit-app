`nexusTypes` is a single object you create once. Pass it to both `createNexusServer` and `createNexusClient` — from that point, every ledger interaction in your entire codebase is fully typed. No `<IouPayload>` generics. No `'package:Module:Template'` strings. TypeScript knows the shape of every Daml contract at every call site.

---

## The pattern

Without `nexusTypes`, you write this everywhere:

```ts
// Server
await nexus.forRequest(req).ledger.contracts.fetchActiveContracts<{
  institution: string;
  asset: string;
  amount: string;
}>({ templateId: 'nexus-example-0.0.1:CollateralRouter:CollateralHolding' });

// React
nexus.useContracts<CollateralHoldingPayload>({
  templateId: 'nexus-example-0.0.1:CollateralRouter:CollateralHolding',
});
```

With `nexusTypes` registered once:

```ts
// Server (oRPC procedure context)
context.ledger.CollateralHolding.findMany({ limit: 100 }); // [!code highlight]

// React hook
nexus.types.CollateralHolding.useContracts(); // [!code highlight]
```

Both call sites get the same payload type — inferred from your Daml codegen. No generics, no strings, no duplication.

## Setup

### 1. Create the registry

```ts title="lib/nexus-types.ts"
import * as DamlPackage from '@daml.js/nexus-example-0.0.1';

const { CollateralRouter } = DamlPackage;

export const nexusTypes = { // [!code highlight]
  JoinRequest:             CollateralRouter.JoinRequest,
  ServiceAgreement:        CollateralRouter.ServiceAgreement,
  CollateralPolicy:        CollateralRouter.CollateralPolicy,
  CollateralHolding:       CollateralRouter.CollateralHolding,
  MarginCall:              CollateralRouter.MarginCall,
  RoutingSuggestion:       CollateralRouter.RoutingSuggestion,
  AllocationRecord:        CollateralRouter.AllocationRecord,
  CollateralAssetMetadata: CollateralRouter.CollateralAssetMetadata,
} as const;

export type NexusTypes = typeof nexusTypes;
```

This file is the **single source of truth**. Adding a new Daml template means adding one line here.

### 2. Pass to the server

```ts title="lib/nexus-server.ts"
import { createNexusServer } from '@nexus-framework/core/server';
import { nexusTypes } from './nexus-types';

export const nexus = await createNexusServer({
  ledgerApiUrl: process.env.CANTON_API_URL,
  auth: { ... },
  session: sessionManager,
  types: nexusTypes, // [!code highlight]
});
```

`nexus.forRequest(req)` now returns `ConstructNexusApi<NexusTypes>` — a typed proxy where every key is a registered template with `create`, `findMany`, `findById`, and `exercise` methods.

### 3. Pass to the browser client

```ts title="lib/nexus-client.ts"
import { createNexusClient, authPlugin, tanstackQueryPlugin } from '@nexus-framework/react';
import { nexusTypes } from './nexus-types';

export const nexus = createNexusClient({
  baseUrl: '/api/ledger',
  plugins: [authPlugin({ basePath: '/api/nexus-auth' }), tanstackQueryPlugin()],
  types: nexusTypes, // [!code highlight]
});
```

`nexus.types.CollateralHolding.*` hooks are now available with full payload type inference.

## Server-side usage (oRPC procedures)

Inside a `ledgerProcedure` handler, `context.ledger` is `ConstructNexusApi<NexusTypes>`. Every method is typed to the exact Daml template:

```ts title="lib/collateral-router.ts"
// Create a contract — createArguments typed from Daml codegen
context.ledger.CollateralHolding.create({ // [!code highlight]
  operator:    context.operatorPartyId,
  institution: context.partyId,
  holdingId:   input.holdingId,
  asset:       input.asset,
  amount:      input.amount.toString(),
  yield:       input.yield.toString(),
  haircut:     input.haircut.toString(),
  expiry:      input.expiry ?? null,
  // Missing a required field? TypeScript error immediately.
  // Added a field that doesn't exist in Daml? TypeScript error.
});

// Query — return type is ActiveContract<CollateralHoldingPayload>[]
const holdings = await context.ledger.CollateralHolding.findMany({ limit: 100 }); // [!code highlight]
holdings[0].payload.asset;   // string ✓
holdings[0].payload.amount;  // string ✓
holdings[0].payload.unknown; // TypeScript error ✗

// Exercise a choice — choice name and argument typed from Daml codegen
context.ledger.RoutingSuggestion.exercise( // [!code highlight]
  input.suggestionCid,
  'ApproveSuggestion',       // only valid choices are allowed
  { approvedBy: context.partyId },
);
```

## React hook usage

In components, the same types flow through `nexus.types`:

```tsx
// Query — no generic, no templateId
const { data, isLoading } = nexus.types.CollateralHolding.useContracts(); // [!code highlight]
// data.contracts[0].payload.asset ← string, from Daml codegen

// Scoped to a party
const { data } = nexus.types.MarginCall.useContracts({ parties: [partyId] });

// Suspense variant
const { data } = nexus.types.RoutingSuggestion.useContractsSuspense();

// Create — createArguments typed
const { mutate } = nexus.types.CollateralHolding.useCreate();
mutate({ createArguments: { institution: partyId, asset: 'UST', ... }, actAs: [partyId] });

// Exercise — choice name and argument typed
const { mutate } = nexus.types.RoutingSuggestion.useExercise('ApproveSuggestion'); // [!code highlight]
mutate({ contractId, choiceArgument: {}, actAs: [partyId] });
```

## What the type system catches

Because payload types come from Daml codegen:

| Change in Daml | What happens in TypeScript |
|----------------|---------------------------|
| Field renamed (`asset` → `assetId`) | Compile error at every `c.payload.asset` call site |
| Field added (new required field) | Compile error in every `create({ ... })` call missing that field |
| Field removed | Compile error anywhere that field is accessed |
| Choice renamed | Compile error in every `useExercise('OldName')` call |
| Choice argument changed | Compile error in `choiceArgument` at the affected call sites |

You find these before deployment. Not in production logs.

## Quick reference

| What you need | Server | React |
|--------------|--------|-------|
| Query contracts | `context.ledger.X.findMany()` | `nexus.types.X.useContracts()` |
| Find by ID | `context.ledger.X.findById(id)` | `nexus.types.X.fetchById(id)` |
| Create | `context.ledger.X.create({ ... })` | `nexus.types.X.useCreate()` |
| Exercise choice | `context.ledger.X.exercise(cid, choice, args)` | `nexus.types.X.useExercise('Choice')` |
| Exercise + return value | — | `nexus.types.X.useExerciseAndGetResult('Choice')` |
