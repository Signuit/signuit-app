All hooks live directly on your `nexus` instance returned by `createNexusClient`. You import the instance, not the hooks individually. They must be called within `nexus.NexusProvider`.

<Callout type="info">
  **If you have `nexusTypes` registered, you should never call these hooks with a generic type parameter or a templateId string.** Use `nexus.types.CollateralHolding.useContracts()` instead of `nexus.useContracts<CollateralHoldingPayload>({ templateId: '...' })`. The hooks documented below are the underlying low-level layer — they exist for cases where you don't have Daml codegen or are building a generic plugin. See [Typed Namespaces](/docs/react/typed-namespaces).
</Callout>

## Query hooks

### useContracts

Fetches the active contracts for a Daml template. Results are cached by TanStack Query, refetched in the background when stale, and invalidated automatically after related mutations.

```tsx
const { data, isLoading, error, isFetching } = nexus.useContracts<PayloadType>({
  templateId: 'package:Module:Template',
  parties: [partyId],    // Optional. Defaults to the party from your auth plugin.
  fetchAll: false,        // Optional. If true, follows all pagination cursors automatically.
  staleTime: 5_000,       // Optional. Milliseconds before a background refetch is triggered.
  enabled: true,          // Optional. Set to false to pause the query.
});

// data.contracts:    ActiveContract<PayloadType>[]
// data.nextPageToken: string | undefined — undefined means you're on the last page
```

### useContractsSuspense

The Suspense variant. Throws a Promise while loading — wrap the component in `<Suspense>`. Inside the component, `data` is always defined and the loading state is never `undefined`.

```tsx
function ContractList() {
  // data is guaranteed to be defined here — Suspense handles the loading state
  const { data } = nexus.useContractsSuspense<PayloadType>({ templateId: '...' });
  return <>{data.contracts.map(...)}</>;
}

export function ContractListPage() {
  return (
    <Suspense fallback={<p>Loading contracts…</p>}>
      <ContractList />
    </Suspense>
  );
}
```

### useInterface

Queries contracts across multiple template types through a shared Daml interface. Each result includes the decoded `interfaceView` alongside the underlying contract.

```tsx
const { data } = nexus.useInterface<InterfaceViewType>({
  interfaceId: 'package:Module:IMyInterface',
  parties: [partyId],
});

// data.contracts[n].interfaceView — typed as InterfaceViewType
// data.contracts[n].contractId, templateId — underlying contract info
```

### usePartyId

Resolves a Canton `userId` to a `partyId` via the participant's identity API. The result is cached for 5 minutes.

```tsx
const { data: partyId } = nexus.usePartyId('alice');
// "Alice::122059a10c..."
```

### useLedgerEnd

Returns the current ledger offset. Refreshes every 2 seconds. Useful for polling-based sync or time-based logic.

```tsx
const { data } = nexus.useLedgerEnd();
// data.offset — current ledger offset string
```

### useSynchronizers

Lists the Canton synchronizers connected to this participant. Refreshes every 30 seconds.

```tsx
const { data } = nexus.useSynchronizers();
// data.synchronizers: SynchronizerInfo[]
```

## Mutation hooks

### useCreateContract

Creates a Daml contract and automatically invalidates the TanStack Query cache for the affected template. Any `useContracts` call for that template will refetch in the background.

```tsx
const { mutate, isPending, error, isSuccess } = nexus.useCreateContract({
  onSuccess: (result) => console.log('Created in tx:', result.transactionId),
  onError: (err) => console.error('Failed:', err.message),
  invalidateTemplates: ['package:Module:Template'], // Optional extra templates to invalidate
});

mutate({
  templateId: 'package:Module:Template',
  createArguments: { owner: partyId, amount: '100' },
  actAs: [partyId],
});
```

### useExerciseChoice

Exercises a Daml choice and invalidates the cache. Returns `SubmitResult` — transaction ID, offset, timestamp. Use `useExerciseAndGetResult` if you need the typed Daml return value.

```tsx
const { mutate, isPending } = nexus.useExerciseChoice({
  invalidateTemplates: ['package:Module:Template'],
});

mutate({
  templateId: 'package:Module:Template',
  contractId: contract.contractId,
  choice: 'Archive',
  choiceArgument: {},
  actAs: [partyId],
});
```

### useExerciseAndGetResult

Exercises a choice and returns the typed Daml return value extracted from the transaction tree. This calls `POST /v2/commands/submit-and-wait-for-transaction` and parses the `exerciseResult` field.

```tsx
interface ApproveSuggestionResult {
  allocationCid: string;
}

const { mutate, data } = nexus.useExerciseAndGetResult<
  {},                        // choice argument type
  ApproveSuggestionResult    // Daml return value type
>({
  invalidateTemplates: [
    'nexus-example-0.0.1:CollateralRouter:RoutingSuggestion',
    'nexus-example-0.0.1:CollateralRouter:AllocationRecord',
  ],
  onSuccess: (result) => {
    // result.result is typed as ApproveSuggestionResult
    console.log('Created AllocationRecord:', result.result.allocationCid);
  },
});

mutate({
  templateId: 'nexus-example-0.0.1:CollateralRouter:RoutingSuggestion',
  contractId: suggestionId,
  choice: 'ApproveSuggestion',
  choiceArgument: {},
  actAs: [institutionPartyId], // The institution is the sole controller — operator is not included
});
```

### useLedgerMutation

An escape hatch for complex operations that don't fit into a single create or exercise. The mutation function receives the full `NexusClient` and can compose any sequence of ledger operations into a single atomic transaction.

```tsx
const { mutate } = nexus.useLedgerMutation({
  mutationFn: async (client, vars: { oldId: string; newAmount: string }) => {
    // Archive the old contract and create a replacement in one transaction
    await client.ledger.commands.exerciseChoice('...', vars.oldId, 'Archive', {}, [partyId]);
    return client.ledger.commands.createContract('...', { amount: vars.newAmount }, [partyId]);
  },
  invalidateTemplates: ['...'],
  onSuccess: (result) => console.log('Done:', result.transactionId),
});

mutate({ oldId: contractId, newAmount: '200' });
```

## SignUIT example — approving a routing suggestion

This is the critical decision point in SignUIT's workflow. The institution approves a `RoutingSuggestion`, which atomically archives it and creates an `AllocationRecord`. The operator is never part of `actAs` — this is enforced by the Daml controller declaration.

```tsx title="components/ApproveButton.tsx"
import { nexus } from '@/lib/nexus-client';

export function ApproveButton({ contractId, institutionPartyId }: Props) {
  // With nexusTypes registered — the right way. No templateId, no generic.
  const { mutate, isPending } = nexus.types.RoutingSuggestion.useExercise('ApproveSuggestion');

  return (
    <button
      disabled={isPending}
      onClick={() =>
        mutate({
          contractId,
          choiceArgument: {},
          actAs: [institutionPartyId], // Only the institution. Never include the operator here.
        })
      }
    >
      {isPending ? 'Approving…' : 'Approve Routing'}
    </button>
  );
}
```

<Callout type="info">
  `actAs: [institutionPartyId]` is not an application-level decision. The Daml `ApproveSuggestion` choice declares `controller institution` — Canton will reject any submission that includes a party other than the institution in `actAs` for this choice.
</Callout>
