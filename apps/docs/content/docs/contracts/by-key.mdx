<Callout type="info">
  If `nexusTypes` is registered, use `nexus.types.X.fetchByKey(predicate)` — no templateId string, no generic. See [Typed Namespaces](/docs/react/typed-namespaces).
</Callout>

`fetchContractByKey` finds the first contract in the ACS whose payload satisfies a predicate function. It is the client-side equivalent of Daml's `fetchByKey` — useful when you need to look up a contract by a business key rather than a `contractId`.

---

## Usage

```ts
// With nexusTypes — preferred
const policy = await nexus.types.CollateralPolicy.fetchByKey(
  (p) => p.institution === institutionPartyId,
);

// Without nexusTypes — manual generic + templateId
const contract = await nexus.ledger.contracts.fetchContractByKey<{
  owner: string;
  amount: string;
  currency: string;
}>(
  'my-package:Iou:Iou',
  (payload) => payload.owner === 'Alice::122059a10c...' && payload.currency === 'USD',
);

if (contract) {
  console.log(contract.contractId);
  console.log(contract.payload.amount);
}
```

---

## Signature

```ts
fetchContractByKey<T>(
  templateId: string,
  keyPredicate: (payload: T) => boolean,
  parties?: string[],
): Promise<ActiveContract<T> | undefined>
```

| Parameter | Description |
|-----------|-------------|
| `templateId` | Daml template ID in `"packageId:Module:Entity"` format |
| `keyPredicate` | Function that returns `true` for the target contract |
| `parties` | Party IDs to query as — optional, defaults to auth token party |

---

## How it works

`fetchContractByKey` calls `fetchAllActiveContracts` internally and applies the predicate with `Array.find`. It returns the **first match**.

For Daml templates that enforce unique keys (via `key` and `maintainer` declarations), there will always be at most one result. For non-unique cases, use `fetchAllActiveContracts` with your own filter.

---

## Common patterns

### Single-field lookup

```ts
// With nexusTypes
const holding = await nexus.types.CollateralHolding.fetchByKey(
  (p) => p.institution === institutionPartyId,
);

// Without nexusTypes
const holding = await nexus.ledger.contracts.fetchContractByKey<HoldingPayload>(
  'nexus-example-0.0.1:CollateralRouter:CollateralHolding',
  (p) => p.institution === institutionPartyId,
);
```

### Compound key

```ts
const holding = await nexus.types.CollateralHolding.fetchByKey(
  (p) => p.institution === institutionPartyId && p.assetId === 'UST_10Y',
);
```

### Scoped to specific parties

```ts
const holding = await nexus.ledger.contracts.fetchContractByKey<HoldingPayload>(
  'nexus-example-0.0.1:CollateralRouter:CollateralHolding',
  (p) => p.institution === institutionPartyId,
  [institutionPartyId, operatorPartyId], // query as both parties
);
```

---

## Performance

`fetchContractByKey` fetches **all** contracts for the template before applying the predicate. For templates with large ACS sizes:

- Add a payload-level `filter` option to `fetchAllActiveContracts` to reduce data transfer before the predicate runs
- Use PQS with a `where` clause for index-backed lookups — see [Advanced: PQS](/docs/advanced/pqs)
- Use `fetchActiveInterfaces` if your Daml model exposes key fields through an interface view
