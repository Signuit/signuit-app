**Nexus Framework** connects the Canton JSON Ledger API v2 to React and TanStack Query. It is the infrastructure [SignUIT](https://signuit.com) is built on — a production multi-party collateral routing application running on Canton Network.

---

## The core idea

You register your Daml codegen types **once**:

```ts title="lib/nexus-types.ts"
export const nexusTypes = { CollateralHolding, MarginCall, RoutingSuggestion, AllocationRecord, ... };
```

Pass that object to both the server and the browser client:

```ts
// Server
createNexusServer({ types: nexusTypes });     // context.ledger.CollateralHolding.findMany()

// Browser
createNexusClient({ types: nexusTypes });     // nexus.types.CollateralHolding.useContracts()
```

From that point, every ledger interaction in your entire codebase — server procedures, React hooks, one-off fetches — is fully typed from your Daml codegen. No `<IouPayload>` generics. No `'package:Module:Template'` strings. If a Daml field is renamed, TypeScript shows a compile error at every affected call site.

## What you get

| Feature | What it means |
|---------|---------------|
| **Single type source** | `nexusTypes` registered once — typed on server and browser, always in sync with Daml |
| **No templateId strings** | `context.ledger.X.findMany()` on server, `nexus.types.X.useContracts()` in React |
| **Plugin-based auth** | `sandboxAuth()`, `jwtAuth()`, `oidcAuth()` — swap auth strategy in one line |
| **Auto cache invalidation** | After a mutation, every affected `useContracts` refetches automatically |
| **Session management** | AES-GCM encrypted HttpOnly cookies, auth endpoints in one call |
| **Real-time streaming** | `useStreamContracts` — WebSocket ACS updates, zero polling latency |
| **SSR prefetch** | Populate TanStack Query cache server-side, client renders without a loading state |
| **PQS support** | Read from PostgreSQL via Canton's Participant Query Store — up to 50× faster for dashboards |
