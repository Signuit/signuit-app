**Nexus Framework** connects the Canton JSON Ledger API v2 to React and TanStack Query. It is the infrastructure [SignUIT](https://signuit.com) is built on — a production multi-party collateral routing application running on Canton Network.

---

## The problem it solves

Building a Canton dApp means dealing with three recurring headaches before you can write a single line of product code:

**Auth is complicated.** Should you use Sandbox HMAC256, JWT, or OIDC? How do you refresh tokens automatically? How do you resolve a userId to a Canton partyId? Each of these has a different answer depending on your environment, and they all need wiring.

**Types disappear at the boundary.** Every time you query a contract, you have to manually write a generic type parameter and copy-paste a templateId string. If the Daml template changes, nothing tells you — runtime errors only.

**The browser-to-Canton bridge is non-trivial.** Canton tokens should never live in the browser. You need a server proxy, a session layer, and a way to scope requests to the right party per user.

Nexus Framework solves all three — once, at setup time.

---

## How it works

You register your Daml generated types once:

```ts title="lib/nexus-types.ts"
import { CollateralHolding, MarginCall, RoutingSuggestion } from '@daml.js/your-package/lib/Module';

export const nexusTypes = { CollateralHolding, MarginCall, RoutingSuggestion };
```

Pass them to the client:

```ts title="lib/nexus-client.ts"
export const nexus = createNexusClient({
  baseUrl: '/api/ledger',
  plugins: [authPlugin(), tanstackQueryPlugin(), nexusTypes],
});
```

And from that point on, every contract query across your entire app is one line — fully typed, no strings, no generics:

```tsx
const { data } = nexus.types.CollateralHolding.useContracts();
const { mutate } = nexus.types.RoutingSuggestion.useExercise('ApproveSuggestion');
```

If a Daml template field gets renamed, TypeScript catches it at compile time. Before it reaches production.

## What you get

| Feature | What it means in practice |
|---------|--------------------------|
| **Plugin-based auth** | One line to switch from sandbox to JWT to OIDC. Token refresh is automatic. |
| **Typed namespaces** | Register your Daml codegen once. Every query, mutation, and fetch is fully typed forever. |
| **Auto cache invalidation** | After a mutation, every affected `useContracts` refetches automatically. No manual `invalidateQueries`. |
| **Real-time streaming** | `useStreamContracts` opens a WebSocket and keeps your UI in sync with zero polling delay. |
| **Session management** | AES-GCM encrypted HttpOnly cookies. Auth endpoints created in one call. |
| **SSR prefetch** | Populate the TanStack Query cache on the server. Client components render without a loading state. |
| **PQS support** | Read directly from PostgreSQL via Canton's Participant Query Store — up to 50× faster than ACS polling for dashboards. |
