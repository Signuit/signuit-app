`createNexus` is the entry point for all Canton Ledger interactions in `@nexus-framework/core`. It assembles a fully configured `NexusClient` from a plugins array — auth strategy, transport settings, and optional package discovery are all plugins.

For React apps, use [`createNexusClient`](/docs/react/setup) from `@nexus-framework/react` instead — it wraps `createNexus` and adds hooks.

## Basic usage

```ts title="lib/nexus.ts"
import { createNexus, sandboxAuth } from '@nexus-framework/core';

export const nexus = createNexus({
  ledgerApiUrl: 'http://localhost:7575',
  plugins: [
    sandboxAuth({
      secret: process.env.SANDBOX_SECRET ?? 'secret',
      userId: 'alice',
      partyId: 'Alice::122059a10c67ef1bb38e4e7ff3fd9c827e2e6cbbfd68bb5cd8fa4c0c56fecdf0734b',
    }),
  ],
});
```

## NexusConfig

```ts
interface NexusConfig {
  /** Canton JSON Ledger API v2 base URL */
  ledgerApiUrl: string;

  /** Plugin array — at minimum one auth plugin is required */
  plugins: NexusPlugin[];

  /** HTTP request timeout in ms. Default: 30_000 */
  timeoutMs?: number;
}
```

## NexusClient namespaces

The returned client exposes three namespaces plus a raw HTTP client:

```ts
interface NexusClient {
  /** Raw CantonClient — for custom HTTP requests not covered by the high-level API */
  http: CantonClient;

  /** Auth utilities */
  auth: {
    /** JWT token management — generation, caching, auto-refresh */
    jwt: JwtManager;
    /** Resolves Canton userId → partyId via /v2/users/{id}/rights */
    partyId: PartyIdResolver;
  };

  /** Ledger operations */
  ledger: {
    /** Fetch active contracts (ACS queries) */
    contracts: ContractQuery;
    /** Create contracts, exercise choices, batch submissions */
    commands: CommandSubmitter;
    /** Ledger end, synchronizer info */
    identity: LedgerIdentity;
  };

  /** Get the current auth token (resolves from whichever auth plugin is active) */
  getToken(): Promise<string>;
}
```

## Plugin-based auth

Auth strategy is a plugin — swap without changing any other code:

  ```ts
  const nexus = createNexus({
    ledgerApiUrl: 'http://localhost:7575',

      sandboxAuth({
        secret: 'secret',          // must match Canton --auth-secret
  ```

  <Tab value="JWT">

  ```ts
  import { createNexus, jwtAuth } from '@nexus-framework/core';

  const nexus = createNexus({

    plugins: [
      jwtAuth({
        token: process.env.CANTON_JWT_TOKEN!,
        refreshToken: async () => fetchNewToken(),
      }),
    ],
  });
  ```

## ledger.contracts

Fetch active contracts from the Canton ACS:

```ts
// First page
const page = await nexus.ledger.contracts.fetchActiveContracts<{ owner: string; amount: string }>({
  templateId: 'my-package:Iou:Iou',
  parties: ['Alice::122059a10c...'],
  pageSize: 50,
});

// page.contracts: ActiveContract<{ owner: string; amount: string }>[]
// page.nextPageToken: string | undefined  — undefined means last page

// All pages (paginates automatically)
const all = await nexus.ledger.contracts.fetchAllActiveContracts({
  templateId: 'my-package:Iou:Iou',
});

// Single contract by ID
const contract = await nexus.ledger.contracts.fetchContractById(
  'my-package:Iou:Iou',
  'contract-abc123...',
);

// By payload predicate (equivalent of Daml fetchByKey)
const byKey = await nexus.ledger.contracts.fetchContractByKey(
  'my-package:Iou:Iou',
  (p) => p.owner === partyId && p.currency === 'USD',
);
```

## ledger.commands

Submit transactions to the ledger:

```ts
// Create a contract
const result = await nexus.ledger.commands.createContract(
  'my-package:Iou:Iou',
  { owner: 'Alice::122059a10c...', amount: '100', currency: 'USD' },
  ['Alice::122059a10c...'], // actAs
);
// result.transactionId, result.offset, result.completedAt

// Exercise a choice (no return value needed)
await nexus.ledger.commands.exerciseChoice(
  'my-package:Iou:Iou',
  contractId,
  'Archive',
  {},
  ['Alice::122059a10c...'],
);

// Exercise and get the typed Daml return value
const exercised = await nexus.ledger.commands.exerciseAndGetResult<
  { newOwner: string },   // choice argument type
  { newContractId: string } // Daml return value type
>(
  'my-package:Iou:Iou',
  contractId,
  'Transfer',
  { newOwner: 'Bob::xyz...' },
  ['Alice::122059a10c...'],
);
// exercised.result.newContractId
```

## ledger.identity

```ts
const end = await nexus.ledger.identity.getLedgerEnd();
// end.offset — current ledger offset

const syncs = await nexus.ledger.identity.getConnectedSynchronizers();
// syncs: SynchronizerInfo[]

const connected = await nexus.ledger.identity.isConnected();
// boolean
```

## getToken

Returns the current bearer token from whichever auth plugin is configured:

```ts
const token = await nexus.getToken();
// Use in custom fetch calls, WebSocket subprotocols, etc.
```

## SignUIT example

SignUIT's server-side client is created via `createNexusServer()` (a higher-level wrapper around `createNexus`). See [Core: Server](/docs/core/server) for how SignUIT wires the full server instance including auth handler, session management, and DAR upload.

For the browser client, SignUIT uses `createNexusClient` from `@nexus-framework/react` with `authPlugin()` for session-based auth — see [React: Setup](/docs/react/setup).
