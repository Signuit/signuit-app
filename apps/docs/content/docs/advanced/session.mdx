Nexus Framework provides a complete, framework-agnostic auth system via `createAuthHandler()`. It handles login, logout, session reading, and token refresh — all as a single `(req: Request) => Promise<Response>` handler you mount at any path.

<Callout type="info">
  This page covers the **server-side** session system. For the client side, see [React: Setup](/docs/react/setup) — specifically `authPlugin()` which calls these endpoints automatically.
</Callout>

---

## createAuthHandler

Returns a universal request handler with four routes built in:

| Method | Path (relative to mount) | Description |
|--------|--------------------------|-------------|
| `POST` | `/login` | Issue session cookie after auth |
| `POST` | `/logout` | Clear session cookie |
| `GET` | `/session` | Read current session — returns `NexusSession` or 401 |
| `GET` | `/refresh` | Extend session TTL |

```ts title="lib/nexus-server.ts"
import { createNexusServer, createAuthHandler, SessionManager } from '@nexus-framework/core/server';
import { sandboxAuth } from '@nexus-framework/core';

export const sessionManager = new SessionManager({
  encryptionKey: process.env.SESSION_ENCRYPTION_KEY,
  ttlMs: process.env.NODE_ENV === 'production'
    ? 2 * 60 * 60 * 1000   // 2h prod
    : 24 * 60 * 60 * 1000, // 24h dev
  secure: process.env.NODE_ENV === 'production',
});

export const nexus = await createNexusServer({
  auth: {
    secret: process.env.SANDBOX_SECRET ?? 'secret',
    userId: 'admin',
    partyId: '',
    getUserId: (ctx) => ctx.session?.userId,
  },
  session: sessionManager,
  ledgerApiUrl: process.env.CANTON_API_URL ?? 'http://localhost:7575',
});

export const authHandler = createAuthHandler({
  nexusServer: nexus,
  session: sessionManager,
  sandboxProvision: true, // auto-allocate Canton parties on first login
});
```

## Login flow with sandbox provisioning

When `sandboxProvision: true`, the login handler:

1. Receives `POST /login` with `{ userId: string }` body
2. Calls `provisionSandboxUser()` — allocates a Canton party + creates ledger user (idempotent)
3. Generates a signed JWT for the party
4. Creates an AES-GCM encrypted session cookie
5. Returns `200` with `Set-Cookie` header

```ts
// Client-side (handled automatically by authPlugin + nexus.auth.useLogin())
const response = await fetch('/api/nexus-auth/login', {
  method: 'POST',
  credentials: 'include',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ userId: 'alice' }),
});
// → 200 + Set-Cookie: nexus_session=<encrypted>; HttpOnly; SameSite=Lax
```

## provisionSandboxUser

Called automatically inside `createAuthHandler` when `sandboxProvision: true`. You can also call it manually for pre-seeding parties:

```ts
import { provisionSandboxUser } from '@nexus-framework/core/server';

// Provision VantageCapital institution party
const { partyId: institutionPartyId } = await provisionSandboxUser(
  nexus.client.http, // raw CantonClient
  {
    userId: 'vantage',
    displayName: 'VantageCapital',
    adminToken: await nexus.client.getToken(),
  }
);

// Provision PrimeBank counterparty party
const { partyId: counterpartyPartyId } = await provisionSandboxUser(
  nexus.client.http,
  {
    userId: 'primebank',
    displayName: 'PrimeBank',
    adminToken: await nexus.client.getToken(),
  }
);
```

## NexusSession

The session object stored in the encrypted cookie:

```ts
interface NexusSession {
  token: string;      // JWT bearer token for Canton API calls
  userId: string;     // Canton userId (e.g. "alice")
  partyId: string;    // Canton partyId (e.g. "Alice::122059a10c...")
  expiresAt: number;  // Unix timestamp in ms
}
```

## SessionManager API

```ts
import { SessionManager, generateEncryptionKey } from '@nexus-framework/core';

const sessionManager = new SessionManager({
  encryptionKey: process.env.SESSION_ENCRYPTION_KEY, // 32-byte hex
  cookieName: 'nexus_session',  // default
  ttlMs: 2 * 60 * 60 * 1000,   // 2 hours
  secure: true,                  // auto-enabled in production
});
```

Generate an encryption key once:

```bash
bun -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
# → SESSION_ENCRYPTION_KEY=a3f8c2d1e4b9...
```

### createSessionCookie

```ts
const cookieValue = await sessionManager.createSessionCookie({
  token: jwtToken,
  userId: 'alice',
  partyId: 'Alice::122059a10c...',
});
// Returns the value for Set-Cookie header
```

### getSession

```ts
const session = await sessionManager.getSession(request.headers.get('cookie'));
// Returns NexusSession | null — null if missing, invalid, or expired
```

### destroySessionCookie

```ts
const clearCookie = sessionManager.destroySessionCookie();
// Returns a Set-Cookie value with maxAge=0
```

## Reading the session on the server

<Tabs items={["TanStack Start", "Next.js"]}>
  <Tab value="TanStack Start">
  ```ts title="src/lib/get-session.ts"
  import { getWebRequest } from '@tanstack/react-start/server';
  import { sessionManager } from './nexus-server';
  import { redirect } from '@tanstack/react-router';

  export async function getSessionOrRedirect() {
    const request = getWebRequest();
    const session = await sessionManager.getSession(
      request.headers.get('cookie')
    );
    if (!session) throw redirect({ to: '/login' });
    return session;
  }
  ```

  ```ts title="src/routes/dashboard/index.tsx"
  import { createServerFn } from '@tanstack/react-start';
  import { createServerNexusClient } from '@nexus-framework/react/server';
  import { getSessionOrRedirect } from '@/lib/get-session';

  const loadDashboard = createServerFn({ method: 'GET' }).handler(
    async ({ request }) => {
      const session = await getSessionOrRedirect();
      const client = await createServerNexusClient({
        request,
        config: { ledgerApiUrl: process.env.CANTON_API_URL! },
      });
      // client is scoped to session.partyId automatically
      return { partyId: session.partyId };
    }
  );
  ```

## Security properties

| Property | Value |
|----------|-------|
| Encryption | AES-256-GCM with random 12-byte IV per session |
| Cookie flags | `HttpOnly`, `SameSite=Lax`, `Path=/` |
| HTTPS | `Secure` flag auto-set when `secure: true` |
| Expiry | Checked on every `getSession()` call |
| No encryption key | Base64 fallback — dev only, not for production |
