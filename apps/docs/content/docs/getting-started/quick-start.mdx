## Step 1 — Wire up the server

The browser client never talks to Canton directly. You need two server-side routes:

- **`/api/nexus-auth`** — login, logout, session, refresh
- **`/api/ledger`** — authenticated Canton proxy

Create a single server module that wires both:

```ts title="lib/nexus-server.ts"
import { createNexusServer, createAuthHandler, SessionManager } from '@nexus-framework/core/server'; // [!code highlight]

export const sessionManager = new SessionManager({
  encryptionKey: process.env.SESSION_ENCRYPTION_KEY, // [!code highlight]
  ttlMs: 2 * 60 * 60 * 1000,
  secure: process.env.NODE_ENV === 'production',
});

export const nexus = await createNexusServer({ // [!code highlight]
  auth: {
    secret: process.env.SANDBOX_SECRET ?? 'secret',
    getUserId: (ctx) => ctx.session?.userId, // [!code highlight]
  },
  session: sessionManager,
  ledgerApiUrl: process.env.CANTON_API_URL ?? 'http://localhost:7575',
});

export const authHandler = createAuthHandler({ // [!code highlight]
  nexusServer: nexus,
  session: sessionManager,
  sandboxProvision: true, // auto-allocates a Canton party on first login // [!code highlight]
});
```

`getUserId` is what makes each request scoped to the right Canton party — it reads the logged-in user's ID from the session cookie and the framework resolves their party ID automatically.

Now mount the two routes:

## Step 2 — Register your Daml types once

This is the step that eliminates every templateId string and generic type parameter in your app. You import the Daml codegen objects and put them in a plain object:

```ts title="lib/nexus-types.ts"
import { // [!code highlight]
  CollateralHolding,
  MarginCall,
  RoutingSuggestion,
  AllocationRecord,
  CollateralPolicy,
  JoinRequest,
  ServiceAgreement,
} from '@daml.js/nexus-example-0.0.1/lib/CollateralRouter'; // [!code highlight]

export const nexusTypes = { // [!code highlight]
  CollateralHolding,
  MarginCall,
  RoutingSuggestion,
  AllocationRecord,
  CollateralPolicy,
  JoinRequest,
  ServiceAgreement,
};
```

When you add a new Daml template, you add one line here. That's the only place you ever touch.

## Step 3 — Create the browser client

```ts title="lib/nexus-client.ts"
import { createNexusClient, authPlugin, tanstackQueryPlugin } from '@nexus-framework/react';
import { nexusTypes } from './nexus-types';

export const nexus = createNexusClient({
  baseUrl: '/api/ledger',
  plugins: [
    authPlugin({ basePath: '/api/nexus-auth' }), // reads session cookie, token never in bundle // [!code highlight]
    tanstackQueryPlugin(), // adds useContracts, useCreateContract, etc. // [!code highlight]
  ],
  types: nexusTypes, // unlocks nexus.types.CollateralHolding.useContracts() // [!code highlight]
});
```

Then wrap your app root with the provider. Because `nexus.NexusProvider` is bound to this exact client instance, there's no risk of context mismatch:

## Step 4 — Query the ledger

Every component can now read Canton contracts in one line. The payload type comes from your Daml codegen — `c.payload.assetId`, `c.payload.callAmount` are all fully typed. TypeScript errors at compile time if a field is missing or renamed.

```tsx title="components/Dashboard.tsx"
import { nexus } from '@/lib/nexus-client';

export function Dashboard() {
  const { data: holdings, isLoading } = nexus.types.CollateralHolding.useContracts(); // [!code highlight]
  const { data: calls }               = nexus.types.MarginCall.useContracts(); // [!code highlight]

  if (isLoading) return <p>Loading…</p>;

  return (
    <div>
      {holdings?.contracts.map((c) => (
        <div key={c.contractId}>
          {c.payload.assetId} — {c.payload.quantity} {c.payload.currency}
        </div>
      ))}
      {calls?.contracts.map((c) => (
        <div key={c.contractId}>
          {c.payload.callAmount} {c.payload.currency} due {c.payload.dueDate}
        </div>
      ))}
    </div>
  );
}
```

## Step 5 — Write to the ledger

Mutations follow the same pattern. The choice name and argument type are inferred:

```tsx title="components/ApproveButton.tsx"
import { nexus } from '@/lib/nexus-client';

export function ApproveButton({ contractId, partyId }: Props) {
  const { mutate, isPending } = nexus.types.RoutingSuggestion.useExercise('ApproveSuggestion'); // [!code highlight]

  return (
    <button disabled={isPending} onClick={() =>
      mutate({ contractId, choiceArgument: {}, actAs: [partyId] })
    }>
      {isPending ? 'Approving…' : 'Approve'}
    </button>
  );
}
```

When this succeeds, the caches for `RoutingSuggestion` and `AllocationRecord` are automatically invalidated. No `invalidateQueries` call needed.

<Callout type="info">
  Generate `SESSION_ENCRYPTION_KEY` once and add it to `.env`:
  ```bash
  bun -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
  ```
  Bun loads `.env` automatically — no dotenv package needed.
</Callout>
