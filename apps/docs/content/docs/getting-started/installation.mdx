## Requirements

- **Bun** ≥ 1.1 · TypeScript ≥ 5 · React ≥ 19 (only for `@nexus-framework/react`)
- A Canton JSON Ledger API v2 endpoint — local sandbox or remote participant

## Start a local Canton Sandbox

The sandbox is the fastest way to get a Canton endpoint running locally — no key infrastructure, no OAuth. It accepts HMAC256 tokens that `sandboxAuth()` generates automatically.

```bash
docker run -p 7575:7575 digitalasset/canton-sandbox:latest
# JSON Ledger API → http://localhost:7575
```

Once it's up, grab a party ID for your config:

```bash
curl http://localhost:7575/v2/admin/parties | jq '.parties[0].partyId'
# "Alice::122059a10c67ef1bb38e4e7ff3fd9c827e2e6cbbfd68bb5cd8fa4c0c56fecdf0734b"
```

## TypeScript config

Nexus Framework is ESM-native. Use the modern module settings:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "strict": true, // [!code highlight]
    "moduleResolution": "bundler", // [!code highlight]
    "module": "Preserve",
    "target": "ES2022"
  }
}
```

`strict: true` is required — the typed namespace system relies on TypeScript's strict inference to catch Daml field mismatches at compile time.

## Framework config

<Tabs items={["TanStack Start", "Next.js"]}>
  <Tab value="TanStack Start">

  No extra config needed — the packages are ESM-native and work with Vite out of the box. This is the setup SignUIT uses:

  ```ts title="vite.config.ts"
  import { tanstackStart } from '@tanstack/react-start/plugin/vite'; // [!code highlight]
  import react from '@vitejs/plugin-react';
  import { defineConfig } from 'vite';

  export default defineConfig({
    plugins: [tanstackStart(), react()],
  });
  ```

  </Tab>
  <Tab value="Next.js">

  Next.js uses CJS by default, so you need `transpilePackages` to handle the ESM packages:

  ```ts title="next.config.ts"
  const nextConfig = {
    transpilePackages: ['@nexus-framework/core', '@nexus-framework/react'], // [!code highlight]
  };

  export default nextConfig;
  ```

  </Tab>
</Tabs>

## Environment variables

```bash title=".env"
# Canton Ledger API
CANTON_API_URL=http://localhost:7575

# Sandbox HMAC256 secret — must match Canton's --auth-secret flag
SANDBOX_SECRET=secret

# Session cookie encryption — generate once:
# bun -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
SESSION_ENCRYPTION_KEY= # [!code highlight]
```

`SESSION_ENCRYPTION_KEY` is required for production session cookies. Leave it empty in dev and Nexus will fall back to base64 (not safe for production).

Bun loads `.env` automatically — no dotenv package needed.
